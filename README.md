# Yar OS

Персональное портфолио **Yaroslav Yuferev · AI Engineer** в формате рабочего стола.
Основа — [Renovamen/playground-macos](https://github.com/Renovamen/playground-macos), MIT. Авторская лицензия сохранена в `LICENSE`.

## Запуск

Требуются Node.js и pnpm (версия указана в `package.json`).

```sh
pnpm install
pnpm dev
```

## Содержание

Данные редактируются в **`src/configs/portfolio.ts`**:

- `name`, `role`, `bio` — профиль;
- `email` — адрес электронной почты;
- `contactForm.formsubmit` — куда доставлять письма из окна «Почта» (текст и вложения до 10 МБ, до 5 файлов). Сайт статический, письма отправляет бесплатный сервис [FormSubmit](https://formsubmit.co): впишите сюда свою почту, отправьте с сайта одно письмо и подтвердите активацию по ссылке из пришедшего письма. После подтверждения FormSubmit пришлёт случайную строку-псевдоним — вставьте её вместо адреса, чтобы почта не была видна в коде сайта. Пока поле пустое, форма проверяет поля, хранит черновик и предлагает написать в Telegram;
- `socials` — LinkedIn, Telegram, Instagram, GitHub: полные ссылки с `https://`, без меток вида `?utm_…`. Пустая ссылка скрывает иконку на сайте (при `pnpm dev` она видна приглушённой заглушкой). Иконки — в «Обо мне» и в окне «Почта», порядок и цвета — `src/configs/socials.ts`;
- `projects` — список проектов; пустой список показывает состояние «раздел готовится».

Пример структуры проекта (демонстрационные данные, заменить реальными):

```ts
{
  title: "Название проекта",
  category: "AI / AUTOMATION",
  description: "Задача, твоя роль и результат.",
  tags: ["Python", "React"],
  url: "https://example.com",
  source: "https://github.com/your-account/project"
}
```

В разделе «Проекты» шесть кейсов: Тендерный паук и Фильтр заявок (с общей главой о том, как они работают вместе), Переводчик документов, LegalHub (с живым демо), Транскрибатор звонков и сайт BONADI. Данные кейсов лежат в `src/components/cases/data/*.ts` (русский и английский текст, код, цифры), LegalHub — в `src/components/legalhub/`. Кейсы написаны по коду проектов, без названий клиентов, имён, адресов серверов и ключей. Отправка писем с сайта включится после активации FormSubmit (см. `contactForm.formsubmit`).
Оформление использует системный шрифт macOS (San Francisco), оригинальные иконки Apple и обои macOS 27 Golden Gate. Источники перечислены в `public/ASSETS.md`.

Иконки и обои — `public/icons/`, `public/wallpapers/`. Цвета обеих тем — `src/styles/theme.css`, интерфейс — `src/styles/portfolio.css`. Приложения — `src/configs/apps.tsx`.

## Языки

Сайт двуязычный: русский и английский. Язык выбирается переключателем «RU | EN» на стартовой странице, значком RU/EN в строке меню, в «Пункте управления» или командой `lang ru | lang en` в терминале. Выбор запоминается (`localStorage`, ключ `yar-lang`); по умолчанию — язык браузера.

Каждый текст пишется сразу на двух языках:

- интерфейс — `src/i18n/ui.ts` (английский словарь обязан иметь те же ключи, что и русский — это проверяет TypeScript);
- о себе и проекты — `src/configs/portfolio.ts` (поля `{ ru, en }`);
- кейс LegalHub — `src/components/legalhub/content.ru.ts` и `content.en.ts`.

Образец договора и интерфейс LegalHub на мониторе намеренно остаются русскими — это реальный русскоязычный продукт.

## Возможности

- Смена темы — кнопкой «солнце/луна» на стартовой странице, в строке меню или в «Пункте управления»: новая тема разливается кругом от нажатой кнопки (View Transitions API, `src/utils/themeTransition.ts`). Без поддержки API или при «уменьшении движения» тема меняется сразу.
- Две темы: светлая (тёплый «льняной» фон вместо белого) и тёмная (тёплый графит). Переключатель — в строке меню и в «Пункте управления»; режим «Авто» следует за системой, выбор запоминается в `localStorage` (`yar-theme`).
- Зелёная кнопка окна (или кнопка «На весь экран» в кейсе) — полноэкранный режим как в macOS: окно занимает весь экран, строка меню и док прячутся, браузер тоже переходит в полный экран. Выход — та же кнопка или Esc. Двойной клик по заголовку — развернуть окно в пределах рабочего стола.
- «Проекты» → LegalHub: обзор, путь пользователя, интерактивное демо (ИИ-разметка страницы, выбор штампа, ошибка, до/после), оба конвейера обработки, архитектура, решения, тесты и фрагменты кода с подсветкой.
- Прямая ссылка на кейс: `?desktop=1&project=legalhub`.
- Демонстрация не подключается к рабочему backend или Dify. Документ и организации вымышлены, переходы статусов имитируются, три PDF подготовлены заранее.
- Контент кейса: `src/components/legalhub/`, оформление: `src/styles/legalhub.css`, PDF: `public/demos/legalhub/`. Генератор: `scripts/generate-legalhub-demo.py` (ReportLab; PT Serif и Arial из macOS) — повторяет договор из `Paper.tsx`.

- Стартовая 3D-сцена: рабочее место — дубовый стол, MacBook, за ним два монитора (редактор с кодом LegalHub и интерфейс LegalHub), блокнот и чашка капучино. Мониторы — `src/components/scene/Monitors.tsx`.
- На экране MacBook — экран блокировки в стиле macOS с анимацией «нажми на меня». Нажатие (или Enter) «разблокирует» его, камера приближается к экрану и открывается портфолио. Кнопка «Открыть портфолио» показывается, только если 3D-сцена недоступна.
- Меню «y.» → «Вернуться к столу»: камера по той же дуге отлетает от экрана к столу, экран снова «блокируется». Пока сцена загружается, на экране остаётся текущий рабочий стол.
- Сцена загружается отдельным модулем. При отключённом WebGL остаётся прямой вход; reduced motion отключает перелёт камеры.
- На экране MacBook — тот же рабочий стол (`<Desktop preview />`, `src/components/scene/ScreenDesktop.tsx`) в пропорциях окна браузера. Камера в конце полёта кадрирует его 1:1, поэтому подмена на настоящий рабочий стол не видна.
- `?desktop=1` открывает интерфейс без сцены.

- Открытие, перемещение, изменение размера, сворачивание и закрытие окон.
- Док фиксированного размера: иконки 64 px, увеличение до 12% без изменения размеров панели, подписи над иконками. На телефоне — 52 px без увеличения.
- «Контакты» открываются с рабочего стола и из профиля; в доке раздел скрыт до заполнения данных.
- Ярлыки рабочего стола и поиск (`⌘/Ctrl + K`).
- Терминал: `help`, `about`, `whoami`, `projects`, `contact`, `open`, `ls`, `pwd`, `date`, `echo`, `clear`; история через стрелки.
- Мобильная компоновка с окнами на ширину экрана.
- Аналитика и внешние медиа исходного шаблона удалены.

## Проверка и сборка

```sh
pnpm typecheck
pnpm build
pnpm serve
```

Результат — статическая папка `dist/`. Для хостинга можно использовать Sites, Vercel, Netlify или любой статический сервер. Настройки Sites сохранены в `.openai/hosting.json`.
